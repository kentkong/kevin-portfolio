# Lifecycle Architecture Studio — v14 design reference

Drop approved reference files here before integration.

**How to add files (Cursor Cloud Agent):**

1. **Chat attachment** — In the agent chat, attach your `.html` file (or drag it onto the message). Ask the agent to save it into this folder.
2. **Paste** — Paste the full HTML into chat and ask the agent to create `your-filename.html` here.
3. **Git** — If you have the repo locally, copy files into this path, commit, and push.

The live Lifecycle Architecture Studio app is **not** changed until you explicitly ask to integrate.
